# 龙族档案 · 绘梨衣主题站

这是一个非官方的《龙族》/绘梨衣主题二次元同人网页原型，不代表官方版权方，也不用于商业用途。

## 内容

- 全屏场景切换：总览、记忆、世界观、档案
- 雨夜与城市主题背景
- 键盘、滚轮和按钮叙事推进
- CG 全屏画廊、缩略图和左右切换
- 粒子、鼠标视差和响应式布局

页面文字为主题化原创改写，不复制原作大段正文。

## 本地预览

在 `anime-site/` 目录执行：

```bash
docker build -t anime-site-preview:local .
docker run --rm -p 8081:80 anime-site-preview:local
```

然后打开 <http://localhost:8081/>。

## 路由

- `/`：总览
- `/work`：记忆片段
- `/about`：绘梨衣档案
- `/404`：迷失的记忆
